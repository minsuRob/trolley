설치가 끝났습니다. 새 터미널 창을 열고 아래 두 가지를 해주세요.

1. 권한 부여

trolley check-permissions --prompt

출력된 경로를 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에 추가하세요. 스크린샷 기능까지 쓰려면 화면 기록에도 같은 경로를 추가합니다. 보안상 이 권한은 반드시 사용자가 직접 켜야 합니다.

2. MCP 등록

claude mcp add trolley -- /usr/local/trolley/bin/trolley mcp

앞으로 업데이트는 trolley update 한 줄이면 됩니다. 경로가 바뀌지 않으므로 권한을 다시 줄 필요도, 관리자 암호도 없습니다.
